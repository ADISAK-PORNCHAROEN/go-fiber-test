# go-fiber-test

# Learning Go and Fiber

This repository is dedicated to learning the Go programming language and the Fiber web framework. The goal is to build a solid foundation in Go syntax and explore modern web development practices.

## Project Objectives
* Master the fundamental syntax and concepts of Go.
* Understand the Fiber web framework for building high-performance APIs.
* Practice project structuring and dependency management in Go.

---

## Core Concepts Covered

### Basic Go
* Variable declarations and primitive data types.
* Control structures (if-else, loops, switch).
* Structs, Maps, and Slices.
* Functions and Error handling.
* Pointers and Memory management basics.

### Fiber Framework
* Setup and Configuration.
* Basic Routing (GET, POST, PUT, DELETE).
* Request parsing and Body validation.
* Response handling (JSON, Text, HTML).
* Working with Middleware.

---

## Technical Stack
* Language: Go (Golang)
* Web Framework: Fiber
* Dependency Management: Go Modules

## หัวข้อที่ได้เรียนรู้

### พื้นฐานภาษา Go (Basic Go)
* การประกาศตัวแปร (Variable Declaration) และชนิดข้อมูล
* โครงสร้างควบคุม (Control Structures) เช่น If-Else, Loop และ Switch
* การใช้งาน Structs, Maps และ Slices
* การจัดการฟังก์ชัน (Functions) และการจัดการข้อผิดพลาด (Error Handling)
* พื้นฐานเรื่อง Pointers และการจัดการหน่วยความจำ

### การใช้งาน Fiber Framework
* การติดตั้งและการตั้งค่าเบื้องต้น
* การจัดการ Routing (GET, POST, PUT, DELETE)
* การรับข้อมูล (Request Parsing) และการตรวจสอบข้อมูล (Validation)
* การส่งข้อมูลตอบกลับ (Response Handling) ทั้งในรูปแบบ JSON และ Text
* การใช้งาน Middleware เบื้องต้น
